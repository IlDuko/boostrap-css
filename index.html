CONCEPTOS PARA PRACTICAR

No tienes que aprenderlo todo de una sentada. Busca un tema y empieza por el ejemplo.

Mostrando 9 lecciones

01 / BASE{ }

Sintaxis CSS

Una regla conecta un selector con una o varias declaraciones. Así le dices al navegador qué elemento cambiar y cómo.

h1 {
  color: #ff7fa8;
}

Clave: selector, propiedad y valor.

02 / BASE</>

Cómo incorporar CSS

Puedes escribir estilos en línea, dentro de una etiqueta <style> o en un archivo externo. Separarlo en otro archivo facilita mantener el proyecto.

<link rel="stylesheet"
      href="style.css">

Clave: elige la forma según el alcance y mantenimiento.

03 / BASE¶

Indentación, herencia y comentarios

La indentación ordena las reglas. Algunas propiedades, como color y font-family, pueden heredarse; los comentarios explican el código sin mostrarse en la página.

/* Estilos de títulos */
h1 {
  color: inherit;
}

Clave: claridad hoy, mantenimiento mañana.

04 / CASCADA#

Niveles de especificidad

Si varias reglas coinciden, la cascada decide cuál aplica. A igualdad de origen e importancia, un selector por ID tiene más especificidad que uno por clase, y una clase más que un tipo.

#protagonista { color: white; }
.personaje { color: pink; }

Clave: escribe selectores claros; reserva !important para casos justificados.

05 / COMPOSICIÓN▦

Flexbox, Grid y breakpoints

Flexbox alinea elementos en un eje; Grid organiza filas y columnas. Los breakpoints marcan anchos donde la composición puede cambiar. Bootstrap ofrece una cuadrícula adaptable lista para usar.

.col-12 .col-md-6
.col-xl-4

Clave: Bootstrap aporta contenedores, filas y columnas por breakpoint.

06 / ADAPTACIÓN⌘

Media queries

Una media query aplica CSS cuando se cumple una condición, como el ancho de la ventana. En esta página, Bootstrap resuelve la distribución adaptable con sus clases responsivas.

@media (min-width: 48rem) {
  /* reglas para pantallas amplias */
}

Clave: adapta el diseño según el contexto de visualización.

07 / DETALLE::

Pseudoelementos

Dan estilo a una parte de un elemento o crean contenido decorativo sin agregar otra etiqueta al HTML.

.titulo::after {
  content: " ✿";
}

Clave: se escriben con doble dos puntos, como ::before y ::after.

08 / DETALLE:)

Pseudoclases

Aplican estilos cuando un elemento está en cierto estado: al pasar el cursor, recibir foco o ser el primero de una lista.

a:hover,
a:focus-visible {
  color: #ff7fa8;
}

Clave: diseña estados de interacción y foco accesibles.

09 / CAPAS▱

Z-index

Ordena elementos que se superponen. Su efecto depende del contexto de apilamiento; suele combinarse con position.

.menu {
  position: relative;
  z-index: 2;
}

Clave: piensa en capas, no solo en un número más alto.
